# Ensayo documental vertical

Skill de edición de video-ensayo 9:16 para HyperFrames: montaje de archivo, tipografía a la voz, collage, documentos resaltados, subtítulos y grade documental.

## Contenido

- `SKILL.md`: guía original, conservada sin cambios.
- `plantillas/grade-documental.json`: preset de color.
- `plantillas/kit.css.html`: estilos compartidos.

## Instalación

Copiar este directorio (sin `.git`) a la carpeta de skills del agente que se utilice, por ejemplo `~/.claude/skills/ensayo-documental-vertical/`. También puede leerse directamente desde Codex con una ruta explícita.

Requiere las skills externas HyperFrames y media-use mencionadas en la guía. La referencia local Wikimedia Vertical, los audios, fuentes, imágenes y proveedores externos no están incluidos. Configurar la ruta de referencia en cada equipo; no asumir que existe en un clon nuevo.

Leer la guía antes de producir. Instalar esta skill no autoriza servicios pagados, transcripciones, generación de medios, publicación ni cambios en una pieza existente. Conservar la voz y aprobaciones vigentes, registrar licencias de archivo y revisar el video exportado con sonido. Las licencias de recursos externos se verifican por separado. No se ha asignado una licencia de software nueva.

Origen: carpeta local de la skill aportada por Erick, snapshot 30/oct/2026. Los tres archivos originales se conservan byte por byte; `SNAPSHOT.json` contiene sus hashes.
